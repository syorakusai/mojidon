# もじどん

2人対戦のリアルタイム単語ゲーム。「3文字目に『か』が入る言葉」のようなお題に対して、
制限時間内にできるだけ多くの単語を入力し、正解数の差で相手にポイントを押し込む。
先に相手へ10ポイント押し切った方が勝ち。

## 遊び方

1. ホストが「ルームを作る」を押すとルームIDが発行される
2. そのIDをゲストに伝える
3. ゲストが「ルームIDで参加」から入室すると自動で対戦開始
4. 各ラウンド30秒間、お題に合う単語をひらがなで入力していく
5. 時間切れで自動判定→結果発表→ホストが「次のラウンドへ」を押して継続

## セットアップ（初回のみ必要な作業）

### 1. GitHub Pages を有効化
リポジトリの Settings → Pages → Source を「Deploy from a branch」、
Branch を `main` / `/(root)` にして保存。

### 2. Firebase Realtime Database のセキュリティルールを設定
このリポジトリの `firebase-rules.json` の中身を、
[Firebaseコンソール](https://console.firebase.google.com/) → プロジェクト `pj-mojidon` →
Realtime Database → ルール タブに貼り付けて「公開」する。

**これをやらないとゲームが動きません**（読み書きが弾かれます）。GitHub側からは自動反映されない、
Firebase側で手動デプロイが必要な設定です。

### 3. Firebase Authentication で匿名認証を有効化
Firebaseコンソール → Authentication → Sign-in method → 「匿名」を有効にする。

## データの仕組み

- 単語辞書: `data/words.json`（ひらがな読み 約18.2万語、MeCab/UniDic系辞書から抽出）
  - 名詞は普通名詞のみ（固有名詞・人名・地名はノイズが多いため除外）
  - 動詞・形容詞は辞書形（言い切りの形）のみ
- 対戦データはFirebase Realtime Databaseの `mojidonRooms/{roomId}` に保存
- 判定はホスト側の端末が両者の提出を集めて実行し、結果をDBに書き込む
  （ゲスト側は結果を読むだけ）

## 初期仕様として決めたこと（変更したい場合は都度相談）

- 促音・拗音（っ・ゃゅょ）や長音（ー）は1文字として数える
- 濁点・半濁点は別文字として扱う（Unicode上もともと別文字なので自然にそうなる）
- カタカナ入力はひらがなへ自動変換して判定
- 漢字入力は非対応（辞書側がひらがな読みのみのため、漢字で打つと不一致になる）
- 品詞は普通名詞・動詞（辞書形）・形容詞（辞書形）
- 同じ単語を両プレイヤーが入力した場合、双方とも独立にカウント（ペナルティなし）
- 自分の中で同じ単語を複数回入力した場合、2回目以降は無効
- お題の(文字, 位置)は辞書内の実在語からランダムに選ぶため、必ず正解が存在する

## 未対応・今後の検討事項

- ルーム一覧・観戦機能なし
- 3人以上の対戦は未対応（2人専用）
- 判定はホスト端末のローカル辞書に依存するため、ホストが辞書データの読み込みに
  失敗すると判定が止まる（エラーハンドリングは簡易的）
- 通信断からの再接続は未検証
